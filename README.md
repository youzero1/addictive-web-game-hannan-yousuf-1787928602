# Neon 2048

A glowing arcade take on tile-merging. Slide tiles with the arrow keys (or swipe on
touch), merge matching numbers, and chase your personal best.

## Modes

- **Classic** — no timer, play until no moves remain. 4×4, 5×5 or 6×6 boards with
  Chill / Normal / Brutal spawn rates.
- **Blitz** — a 3 minute countdown starts on your first move.
- **Daily** — everyone gets the same tile sequence each day; resets at midnight.

## Features

- Limited power-ups: Zap a tile, shuffle the board, swap two neighbours. Extra
  charges are earned every 2,000 points.
- Synthesised sound effects with a mute toggle.
- Three colour themes: Neon, Retro CRT, Pastel.
- Badges, daily streaks, career stats and a personal top-10 leaderboard — all saved
  on the device.
- One-tap shareable score card.

## Running locally

```bash
npm install
npm run dev
```

Then open the printed local URL.
